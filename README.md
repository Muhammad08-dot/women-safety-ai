# 🚨 Women Safety AI Platform (محفوظ پاکستان)

Production-Grade Proactive Safety Platform providing Voice-Triggered Emergency SOS ("Bachao"), Graph AI Safe Route Recommendation, Movement Anomaly Detection, and Fake Escape Call Generator.

## Architecture

- **Backend:** FastAPI (Python 3.11+) + Anomaly Detection Engine + Mapbox Routing
- **Frontend:** Next.js 15 + TypeScript + PWA Support
- **Infrastructure:** Docker Compose

## Quick Start

```bash
cd women_safety_ai
docker compose -f infrastructure/docker/docker-compose.dev.yml up --build
```
